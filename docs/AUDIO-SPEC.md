> 상태: 규격(claude-main, 2026-11-27). 사용자 결정: 효과음·배경음 추가, **무료 상업용(CC0) 음원** 사용. 배경음 곡은 후보를 들어 보고 사용자가 고른다.

| 항목 | 결정 |

| 효과음 | CC0 효과음 팩에서 골라 쓴다(예: Kenney). 코드 합성 아님 |
| 배경음 | 후보를 사용자가 듣고 선택. 1·2차 후보(중세·RPG 필드·칩튠 7곡) 모두 불채택 → **웅장한 판타지 전투풍**(현악·브라스·드럼, 모험·전투 긴장감)으로 방향 변경(사용자 결정 2026-11-27) |

## 2. 원칙

- 소리는 **표현 전용**: 코어·세션 상태와 리플레이에 영향 없음. 렌더 계층(Phaser)이 이벤트를 보고 재생한다(이벤트 → 소리 매핑은 한 파일).
- 형식 `.ogg`(Android WebView·데스크톱 Chromium 재생), 44.1kHz, 효과음 모노·짧게(대부분 1초 미만), 배경음 스테레오 반복 재생 가능한 곡(이음매 자연스럽게). 전체 오디오 용량 목표 3MB 이하.
- 위치 `public/assets/audio/sfx-<이름>.ogg`, `bgm-<이름>.ogg`. 없거나 실패한 파일은 그 소리만 생략(오류 없음, 그림 대체 규칙과 같음).
- 첫 터치 전에는 브라우저 정책상 소리가 막힐 수 있다 → 첫 사용자 입력 때 오디오 잠금 해제.

## 3. 효과음 목록

| 이름 | 언제 | 느낌 |
|---|---|---|
| `sfx-tap` | HUD 버튼 누름(타워 선택·배속·메뉴 등) | 짧고 가벼운 클릭 |
| `sfx-error` | 명령 거부 피드백(골드 부족 등) | 낮은 "뚝" |
| `sfx-build` | 타워 설치 성공 | 돌·나무 놓는 "쿵" |
| `sfx-upgrade` | 강화 성공 | 반짝 올라가는 소리 |
| `sfx-sell` | 판매 | 동전 소리 |
| `sfx-wave-start` | 웨이브 시작(지금 시작·자동) | 짧은 뿔나팔·북 |
| `sfx-arrow` | 궁수탑 발사 | 가벼운 활 시위 |
| `sfx-bolt` | 발리스타 발사 | 묵직한 쇠뇌 |
| `sfx-fire` | 마법탑(불) 발사 | 불꽃 "휙" |
| `sfx-explode` | 마법탑 폭발 | 작은 폭발 |
| `sfx-frost` | 서리탑 명중 | 얼음 깨지는 "칭" |
| `sfx-enemy-die` | 적 처치 | 짧은 "퐁"(귀엽게, 잔혹하지 않게) |
| `sfx-base-hit` | 적이 기지 도달(기지 피해) | 둔탁한 경고음 |
| `sfx-victory` | 스테이지 승리 | 짧은 팡파레 |
| `sfx-defeat` | 스테이지 패배 | 짧은 하강음 |

- **과다 재생 제한:** 같은 효과음은 실제 시간 기준 최소 간격(발사·명중·처치 약 60~80ms)과 동시 재생 수 상한(같은 이름 3~4개). 5×에서도 소리가 뭉개지거나 커지지 않게. 일시정지 중에는 게임 이벤트 소리 없음(버튼 소리만).
- 음량: 효과음끼리 상대 음량 정리(발사 소리는 작게, 승리·패배는 크게).

## 4. 배경음

- `bgm-main`: 스테이지 선택·전투 공통 1곡(사용자가 2곡을 원하면 `bgm-select`·`bgm-battle`로 분리). 반복 재생, 효과음보다 작게.
- 메뉴(일시정지) 중에는 볼륨을 낮춰 계속, 결과 화면에서는 이어서 재생(승리·패배 효과음이 먼저 들리게 잠깐 낮춤).
- **앱이 숨겨지면(백그라운드·화면 꺼짐) 배경음·효과음 정지, 돌아오면 재개**(UI-CONTRACT 5절 숨김 규칙과 같은 신호).

## 5. 설정

- `⚙` 메뉴와 스테이지 선택 화면에 **효과음 켜기/끄기**, **배경음 켜기/끄기** 두 토글(기본 켜짐). 문구는 `strings.ko.ts`.
- **크레딧:** CC-BY 음원을 쓰면 스테이지 선택 화면의 `크레딧`(또는 ⚙ 메뉴) 안에 `곡명 — 작곡자 (라이선스, 출처)`를 표시한다. 라이선스가 요구하는 표기(제목·저작자·라이선스 링크·변경 여부)를 빠짐없이.
- 설정은 기기에 저장(localStorage 별도 키 `ddooby-defence.audio`, 진행 저장과 분리). 저장 실패해도 게임 진행 영향 없음(이번 실행 동안만 유지).
