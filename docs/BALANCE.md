## 3. 검증 봇 (결정적, 난수 없음)

밸런스는 사람이 아니라 **고정 규칙 봇**으로 먼저 측정한다. 봇은 시도 코어(`createAttempt`)에 `submit`만 하는 순수 TS 코드이고, 같은 입력이면 같은 결과다.

### 3.1 공통 규칙

- **자리 점수:** 칸 `(col,row)`의 점수 = 그 칸 중심에서 해당 타워 Lv1 사거리 안에 들어오는 경로 길이(경로를 100mt 간격으로 표본화한 점의 수). 설치 가능 칸(경로·예약·점유 제외)만. 동률은 `row` 작은 순 → `col` 작은 순.
- **행동 시점:** 매 틱 시작 전에 판단한다(코어 1단계 명령 적용 규칙 그대로). 한 틱에 명령 여러 개 가능.
- **웨이브 시작:** 기본은 준비 타이머 만료(`startWave` 안 함). `조기 시작` 변형만 준비 단계 진입 다음 틱에 `startWave`.
- **타깃:** 기본값(선두) 유지. 판매 없음(별도 시나리오 제외).
- 봇 정의·자리 점수 함수는 테스트로 결정성을 고정한다(같은 번들 2회 실행 = 같은 결과·틱별 해시).

### 3.2 봇 목록

| ID | 이름 | 규칙 | 의미 |
|---|---|---|---|
| B0 | 무대응 | 아무것도 안 함 | 웨이브가 실제 위협인지 |
| B1 | 균형 | 정해진 구성 순서(예: 궁수→서리→마법→발리스타 반복)로 가장 점수 높은 칸에 설치, 설치할 돈이 없으면 강화(가장 낮은 레벨·먼저 지은 순). 설치 상한 N개 이후에는 강화 우선 | 능숙한 플레이 |
| B2 | 초보 | 가장 싼 타워만, 점수 **중간 순위** 칸에 설치, 강화 안 함, 보유 골드 절반만 사용 | 처음 하는 사람 |
| B3a~d | 단일 종류 | B1과 같은 규칙이지만 한 종류(궁수/발리스타/마법/서리)만 | 상성·혼합의 가치 |
| B4 | 균형+조기 시작 | B1 + 매 준비 단계 즉시 시작 | 서두르는 플레이 |

봇 세부(구성 순서·설치 상한 N 등)는 구현에서 정하고 문서·보고에 적는다. 단, 후보 수치에 맞춰 봇을 유리하게 바꾸는 것은 금지(봇 규칙 변경은 이유를 기록하고 claude-main 확인).

### 3.3 구현 확정값 (BAL-01, `src/game/balance/bots.ts` `BOT_PARAMS`)

- **설치 상한 N = 6**, **구성 순서 = 궁수 → 서리 → 마법 → 발리스타 반복**(6번째까지: 궁수·서리·마법·발리스타·궁수·서리).
- **공통 결정 규칙(B1·B3·B4·B5):** 매 결정 시점(틱)마다 상한 전이면 구성 순서의 다음 타워를 가장 점수 높은 빈 칸에 설치(골드가 충분하면 한 틱에 여러 개, 틱 안에서 골드를 로컬 추적). 돈이 모자라면 **강화로 새지 않고 다음 틱까지 모은다**(설치 우선; 문장대로 "돈이 없으면 강화"를 하면 설치가 계속 굶음). 상한에 도달하면 가장 낮은 레벨(동률은 먼저 지은 순) 타워를 살 수 있을 때 강화한다.
- **자리 점수:** 타워 Lv1 사거리 안에 들어오는 경로 표본 수(경로를 100mt 간격으로 표본, 칸 중심 기준, 경계 포함). 동률은 row 작은 순 → col 작은 순. 타워 종류마다 자기 Lv1 사거리로 계산.
- **B2:** 궁수만, 점수 > 0 인 설치 가능 칸의 **중간 순위** 칸, 강화 없음, 설치 비용 × 2 ≤ 보유 골드일 때만 설치.
- **B3a~d:** B1 과 같으나 구성이 한 종류(궁수/발리스타/마법/서리)뿐.
- **B4:** B1 + 첫 틱 이후 각 준비 단계의 첫 결정에서 `startWave`.
- **B5(역할 점검용 추가 봇):** B1 에서 서리를 제외. BALX-09 의 "서리 제외 시 S3 결과가 나빠짐" 확인용.
- 한 결정 시점에 여러 명령을 낼 수 있고 명령은 다음 틱에 적용된다. 후보 수치를 위해 이 규칙을 바꾸지 않았다.
- **역할 측정:** 스테이지 2 경로, 골드 800, 웨이브 1 을 단일 적 종류 × 단일 타워 종류로 대체(일반 30@500ms, 고속 30@350ms, 중장 14@1200ms, 군집 60@150ms — 후보에 맞춰 조정하지 않은 고정값), 가능한 만큼 설치 후 즉시 시작.

## 5. 역할 점검 (SPEC 3절 역할 → 수치)

전용 측정 시나리오(한 종류 적만 나오는 웨이브, 같은 골드로 한 종류 타워)로 확인한다.

| 타워 | 역할 | 기대 |
|---|---|---|
| 궁수 | 높은 연사·단일 | 공격 주기 가장 짧음. 고속형 상대 골드당 처치가 가장 좋거나 2위 |
| 발리스타 | 최장 사거리·강한 단일·낮은 연사 | 1발 피해 최대, 중장형 상대 골드당 피해 최고 |
| 마법 | 고정 지점 범위 | 경량 군집형 상대 골드당 처치 최고 |
| 서리 | 약한 피해 + 둔화 | 단독 DPS 최저, 다른 타워와 섞을 때 B1 대비 기여(서리 빼면 결과가 나빠짐) |

| 적 | 성격 | 기대 |
|---|---|---|
| 일반형 | 기준 | — |
| 고속형 | 빠르고 약함 | 이동속도 최대, 서리·궁수에 약함 |
| 중장형 | 느리고 단단, 기지 피해 큼 | HP·기지 피해 최대 |
| 경량 군집형 | 약하고 밀집 | HP 최저, 밀집 생성(짧은 간격)·군집 사이 긴 공백 |

## 6. 웨이브 설계 의도 매트릭스 (SPEC 6절, 데이터와 분리)

| 스테이지 | W1 기본 대응 | W2 특정 적 강조 | W3 새 조합 | W4 복합 대응 | W5 종합 도전 |
|---|---|---|---|---|---|
| Stage 1 (일반·고속 중심, 4종·3특성 모두 등장) | 일반형 | 고속형 + 속도 강화 | 중장형(체력 강화) + 군집 | 일반(제어 저항) + 고속 + 중장 | 전부 혼합 |
| Stage 2 (중장·군집·특성 조합) | 일반 + 소수 군집 | 중장형 다수 | 군집(제어 저항) + 고속(속도 강화) | 중장(체력 강화) + 군집 | 중장·군집 특성 조합 대량 |
| Stage 3 (종합 활용) | 일반 + 고속 | 고속(속도 강화) 다수 | 중장 + 군집 동시 | 3종 혼합 + 특성 | 4종·3특성 종합 |

압박 목표: 각 스테이지 W1은 기본 배치만으로 막을 수 있고, W3에서 "새 조합"이 기존 배치의 약점을 드러내며, W5는 B1 기준 남은 HP 감소의 대부분이 일어나는 웨이브.

## 8.1 Stage 4·5 추가 (STAGE-45, 사용자 결정 2026-11-27)

- 테마: Stage 4 = 설원 그림(Stage 2 타일 재사용), Stage 5 = 폐허 그림(Stage 3 타일 재사용). 경로는 새로(SIM-CONTRACT 10.2 후보).
- 특화: Stage 4 = 고속형·속도 강화 위주(웨이브 적 수의 절반 이상이 고속형, 속도 강화가 3개 웨이브 이상), Stage 5 = 중장형·체력 강화·제어 저항 위주(중장형 비중 최대 **(기본 체력 합 기준 = 스테이지 전체 개체 수 × 기본 HP, 특성 배율 제외, claude-main 결정 2026-11-27)**, 체력 강화·제어 저항이 각각 2개 웨이브 이상).
- 난이도: 점점 어렵게(캐주얼 유지). 타워·적·특성·경제 공통 수치(Stage 1~3 승인값)는 **바꾸지 않고** Stage 4·5의 초기 골드·기지 HP·웨이브만 정한다.
- 기준 확장(4절 표에 추가 적용):
  - BALX-01 B0: Stage 4·5도 웨이브 3 안에 패배.
  - BALX-02·03 B1: Stage 4·5 승리, 남은 기지 HP **Stage 4 30~85%, Stage 5 25~80%**, 그리고 S3 ≥ S4 ≥ S5 경향(같거나 감소, 차이 허용 ±10%p).
  - BALX-04 B2: Stage 4·5 패배.
  - BALX-05 B3: Stage 4·5 각각 단일 종류 2종 이상 패배.
  - BALX-07 시간: Stage 4 B1 240~360초, 웨이브당 전투 30~75초. **Stage 5 예외: 54칸 경로·중장 속도(끝까지 88초)로 웨이브당 전투 ≤ 90초, 스테이지 ≤ 390초**(claude-main 결정 2026-11-27, 첫 웨이브 준비 15초 반영해 380→390, 사용자 보고 예정). 하한(240초·30초)은 그대로.
  - BALX-11(신규) 특화: 위 "특화" 조건을 데이터로 확인(S4: 고속형 개체 수가 전체의 절반 이상 + 속도 강화 고속형이 나오는 웨이브 ≥ 3, S5: 중장형 기본 체력 합이 다른 3종 각각보다 큼 + 체력 강화·제어 저항 중장형이 나오는 웨이브 각 ≥ 2).
  - 구현 해석(보고): BALX-05 는 Stage 3·4·5 각각에서 단일 종류 2종 이상 패배 + 승리한 종류는 B1 보다 남은 HP 적음, BALX-04 는 B2 가 S3·S4·S5 모두 패배.
- 버전: `contentVersion` `bal-01-v1` → **`bal-02-v1`**(Stage 1~3 값 불변, Stage 4·5 추가). 사용자 실기기 플레이 후 승인.
